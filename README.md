# Maratoncito

A self-hosted web app for discovering, requesting, searching, and downloading movies and TV shows via torrents, with persistent audio/subtitle profiles and preferred release groups per season.

The goal is to consolidate the workflows usually spread across Sonarr, Radarr, Bazarr, and Jellyseerr/Overseerr into one interface, while initially using Prowlarr for indexer aggregation and qBittorrent for downloads.

## Project status

Early-stage project. See the [implementation plan](docs/IMPLEMENTATION_PLAN.md) for the proposed architecture, component responsibilities, release selection behavior, and delivery phases. Features described there are **planned, not yet implemented**.
